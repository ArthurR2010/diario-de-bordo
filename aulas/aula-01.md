# Aula 01

## O que aprendi

Na primeira aula, fui apresentado aos conceitos do GitHub. Aprendi a criar um repositório e a documentar projetos para acompanhar o meu processo de aprendizagem. Também pratiquei o trabalho em equipe no GitHub, usando conceitos como commit, main, branch, pull request e merge.

## Termos novos

- **Commit:** um ponto de salvamento do projeto. Registra o que foi alterado, com mensagem, autor e data.
- **Main:** a branch principal, em que está localizada a versão oficial do projeto.
- **Branch:** uma linha de trabalho paralela, sendo possível realizar alterações sem afetar a versão oficial.
- **Pull Request (PR):** um pedido para juntar as mudanças de uma branch na outra, possibilitando revisão e conversa em equipe.
- **Merge:** a ação de juntar as mudanças de uma branch em outra.
